# Lodgent

Agent-ready direct booking for independent hotels. Lodgent makes a hotel's rooms, rates and attributes machine-readable and bookable by AI agents through an MCP server and a REST API. Bookings go straight to the hotel's PMS for a small fee instead of an OTA commission.

> Work in progress. See [PLAN.md](PLAN.md) for status.

## Quick start

```bash
pnpm install
docker compose up -d
pnpm dev
```
