# Setup needed

Everything runs locally without any of these: `pnpm dev` uses a fake Apaleo, a fake Stripe, fixture LLM
providers, Mailpit and a dev sign-in. This is the list of real accounts and keys needed to go live.
It is kept up to date as integrations land.

| # | What | Why | Where it goes |
| --- | --- | --- | --- |
| 1 | GitHub repository `lodgent` with the Claude GitHub App installed | Push code, run CI | github.com |
| 2 | **Apaleo developer account + "connected app" (store app) registration**: client id/secret, redirect URI `<API_BASE_URL>/v1/integrations/apaleo/callback`, scopes `offline_access setup.read rates.read availability.read reservations.manage folios.manage` plus the scope Apaleo requires for webhook subscriptions (check apaleo.dev → API scopes; set `APALEO_SCOPES` if it differs) | Hotels connect their Apaleo account; live rates and reservations | `APALEO_CLIENT_ID`, `APALEO_CLIENT_SECRET`, `APALEO_SCOPES`, URLs `https://identity.apaleo.com`, `https://api.apaleo.com`, `https://webhook.apaleo.com` |
| 3 | An **Apaleo sandbox/test account** with at least one property whose rate plans are distributed on the `Ibe` channel | Verify the all-in price calculation (ADR 0006) and the end-to-end booking | Connect it from the dashboard |
| 4 | A random `APALEO_WEBHOOK_TOKEN` and `SIGNING_SECRET` (32+ bytes each) | Webhook endpoint secret, signed OAuth state / checkout links | Secrets Manager (see infra) |
| 5 | **Anthropic API key** (Claude Platform) with access to the model in `ANTHROPIC_MODEL` (default `claude-sonnet-5-5`) | Website import: attribute and description extraction with verified quotes. Without it, the offline keyword matcher is used | `ANTHROPIC_API_KEY` |
| 6 | **Embeddings key**: Voyage AI (`EMBEDDINGS_PROVIDER=voyage`, model `voyage-3.5`) or OpenAI (`EMBEDDINGS_PROVIDER=openai`, `text-embedding-3-small`) | Semantic matching in agent search. The local hash embedding is for dev/test only | `VOYAGE_API_KEY` or `OPENAI_API_KEY` |
| 7 | **Stripe platform account** with **Connect** enabled (platform profile completed, branding set, Standard/full-dashboard connected accounts allowed in the countries you serve) | Hotels onboard through Stripe-hosted Account Links; guests pay the hotel directly (ADR 0009) | Stripe Dashboard → Connect |
| 8 | **Stripe API keys**: test-mode keys for staging, live keys for production | Server SDK and Stripe.js | `STRIPE_SECRET_KEY`, `STRIPE_PUBLISHABLE_KEY` (Secrets Manager) |
| 9 | **Two Stripe webhook endpoints**, both at `<API_BASE_URL>/webhooks/stripe`: one for your account's events and one for **Connected accounts** events. Events: `payment_intent.amount_capturable_updated`, `payment_intent.succeeded`, `payment_intent.payment_failed`, `payment_intent.canceled`, `setup_intent.succeeded`, `setup_intent.setup_failed`, `account.updated`, and on the account endpoint also `invoice.finalized`, `invoice.paid`, `invoice.payment_failed`, `invoice.voided`, `invoice.marked_uncollectible` | Booking finalization, onboarding status, fee invoices | `STRIPE_WEBHOOK_SECRET`, `STRIPE_CONNECT_WEBHOOK_SECRET` |
| 10 | In the Apaleo sandbox, check whether bookings with a **`CreditCard` guarantee** need payment-account details (Apaleo Pay); confirm pay-at-hotel bookings are accepted with the card kept in Stripe | Pay-at-hotel rates (ADR 0009) | Apaleo sandbox |
| 11 | **AI visibility API keys** (any subset): Anthropic (reuses #5), OpenAI, Google Gemini, Perplexity. Confirm the model names (`OPENAI_MODEL`, `GEMINI_MODEL`, `PERPLEXITY_MODEL`) and the per-token and search prices in `packages/llm/src/visibility.ts` against current price lists (ADR 0010) | Weekly checks of how assistants answer travellers; without keys, local development shows simulated results | `OPENAI_API_KEY`, `GEMINI_API_KEY`, `PERPLEXITY_API_KEY` |
| 12 | **Stripe Billing on the platform account**: invoice branding (logo, colours, public business details), invoice numbering prefix, tax settings (VAT on the platform fee for EU hotels; consider Stripe Tax and collecting hotels' VAT IDs) and **customer emails for finalized invoices** turned on, so hotels receive the monthly fee invoice by email | Monthly invoices for pay-at-hotel booking fees (ADR 0011) | Stripe Dashboard → Settings → Billing / Invoices |
| 13 | Confirm the **Apaleo app deep link** for a reservation (default `https://app.apaleo.com/{propertyId}/reservations/{reservationId}`) by opening one in the Apaleo app | "Open in Apaleo" links in the bookings dashboard | `APALEO_RESERVATION_URL_TEMPLATE` |
